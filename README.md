# Access Signal-to-Action Value Model

An interactive, client-calibrated model for exploring the commercial value of faster market-access response.

## What the model supports

- Exact number entry and slider-based exploration
- Conservative, illustrative-base, and higher-exposure presets
- Externally estimated Jardiance 2027 scenario for multisource generic dapagliflozin
- Named scenarios saved in the local browser
- CSV import and export for Excel-based assumption updates
- Response-time sensitivity analysis
- Explicit methodology and limitations

## Important interpretation note

This is a decision-support framework, not a validated ROI claim. It estimates protected prescriptions by summing the weekly area between the current-response and AI-enabled run-rate curves. Before external use, calibrate the erosion rate, response-time gap, response effectiveness, and other assumptions using brand data or a defensible analog.
